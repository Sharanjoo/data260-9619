# AI Use Disclosure

## 1. What I used an AI assistant for and what I did myself

I used an AI assistant to organize the assignment, create a checklist, improve the project structure, and help with documentation. I personally verified my SID settings, ran the project, reviewed the results, and captured the evidence.

## 2. One AI-produced output that was wrong or unsuitable

The original JavaScript checked the browser’s general validation before the assignment-specific description and terms checks. This prevented the required custom alerts from appearing.

## 3. How I detected or verified the problem

I tested a short description and an unchecked terms box. The browser displayed its default message instead of my custom alert.

## 4. What I changed and why it works now

I moved the description and terms checks before the general validation. The required custom alerts now appear correctly.
